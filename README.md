# Стартовый экран для Media Station X

Экран для телевизора: приветствие, дата и время, погода в Иркутске, ярлык на Lampa, свои фото.

## Как подключить на телевизоре

MSX → Settings → Start Parameter → Setup → ввести `raw.githack.com/holylolka/tv/main`, замок НЕ включать.

Телевизор 2014 года не открывает HTTPS-сертификат GitHub Pages (ошибка «status 0»), поэтому экран отдаётся по обычному http через raw.githack.com.

## Как устроено

- `build.mjs` собирает JSON-файлы в `msx/`. GitHub Actions запускает его каждый час (погода с open-meteo.com) и при каждом изменении репозитория.
- `photos/` — сюда класть свои `.jpg`/`.png`, они сами появятся в разделе «Фото». Репозиторий публичный: эти фото может открыть любой, кто знает адрес.
- `img/bg.jpg` — фон, нарисован скриптом `tools/make-bg.ps1`. Можно заменить любой картинкой 1920×1080 с тем же именем.
- Город и приветствие — в начале `build.mjs` (`CITY`, `GREETING`).
